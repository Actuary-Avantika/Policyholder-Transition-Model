What does this model do?

This model represents an insurance policyholder portfolio as a discrete-time Markov Chain.

At each observation period, a policyholder can move between different states such as remaining active, entering a claim state, lapsing or becoming closed.

Key idea: The probability of the next state depends on the policyholder's current state.

Model states

ACTIVE

Policy remains in force.

CLAIM

Policyholder is in a claim-related state.

LAPSED

Policy has lapsed.

CLOSED

Policy has reached the absorbing state.

Actuarial application

A transition model of this type can be used to project the future composition of an insurance portfolio.

For example, an insurer could use historical policyholder experience to estimate transition probabilities and then project the expected number of active, claiming, lapsed and closed policies over time.

Expected time to absorption

Using the fundamental matrix of the chain, N = (I - Q)-1, where Q is the sub-matrix of transition probabilities between transient states only, N·1 gives the expected number of periods a policyholder spends before being absorbed into Closed.

N = (I - Q)-1   |   t = N · 1

Long-run interpretation

Stationary distribution: a distribution satisfying πP = π.

Absorbing state: a state that, once entered, cannot be left.

Expected time to absorption: the expected number of periods before a policyholder reaches an absorbing state.

Long-run behaviour: what the process approaches as the number of transitions becomes large.

Important: Stationary distribution, absorbing states, expected time to absorption and long-run behaviour are related concepts, but they are not identical.

Methodology
How the Policyholder Transition Model works.

What is being modelled?

The model represents an insurance policyholder portfolio as a discrete-time Markov Chain.

States

  • Active
  • Claim
  • Lapsed
  • Closed

Transition matrix

The transition matrix contains the probability of moving from each current state to each possible next state.

Pij = P(Xt+1 = j | Xt = i)

Rows represent current states and columns represent next states.

Initial distribution

π0 = (1, 0, 0, 0)

The default model begins with 100% of policyholders in the Active state.

n-step transition probabilities

The n-step transition matrix is obtained by multiplying the transition matrix by itself n times.

Pn = P × P × ... × P

The individual entry Pnij gives the probability of being in state j after n transitions, conditional on starting in state i.

Portfolio projection

πn = π0Pn

This gives the probability distribution of the portfolio after n transitions.

Stationary distribution

πP = π

A stationary distribution is a distribution that remains unchanged under the transition matrix.

Absorbing states & expected time to absorption

A state is absorbing when the process remains in that state once it enters it.

Pii = 1

In the default model, Closed is an absorbing state. The expected number of periods a policyholder spends in transient states before absorption is obtained from the fundamental matrix N = (I - Q)-1, where Q contains the transition probabilities restricted to transient states.

Estimating a transition matrix from data

The base matrix used throughout this app is a hypothetical assumption. The Data & Estimation tab illustrates how it could instead be estimated from observed policyholder experience, using the maximum-likelihood estimator for a time-homogeneous discrete-time Markov chain — the observed count of i → j moves divided by the total moves out of state i.

P̂ij = Nij / Ni·

Major assumptions

  • Transition probabilities are assumed to remain constant over the projection period.
  • The model is discrete-time.
  • The future state depends on the current state through the specified transition probabilities.
  • The base transition probabilities are hypothetical; the Data & Estimation tab shows how real data would be used instead.
  • The financial impact figure on the Portfolio Projection tab is illustrative only, not a reserving calculation.

Limitations

  • The model does not use actual insurer policyholder data.
  • Transition probabilities are not estimated from real experience (only from simulated data, for demonstration).
  • The current model does not explicitly represent new business.
  • Economic conditions and policyholder characteristics are not explicitly modelled.
  • Real actuarial models may require additional states, segmentation and time-varying assumptions.

Real-world actuarial application

In a real insurance setting, transition probabilities could be estimated using historical policyholder experience.

For example, an insurer could analyse policy records to estimate the probability of remaining active, entering a claim state, lapsing or closing during each observation period.

The resulting transition matrix could then be used for portfolio projections, experience analysis, scenario testing, reserving-related cost estimates and other actuarial investigations.
